# Data Structures & C/C++ coursework

Coursework from the C, C++ and data-structures courses at SCE, grouped by topic.

## Layout
- **`intro-c/`** — first-year C course (Keren Kalif): `assignment-1` … `assignment-5`, `labs`, and `practice`.
- **`data-structures/`** — linked lists, stacks, queues, hashing, BSTs (`linked-list`, `list-and-queue`, `mixed-structures`, `bst-library`, …).
- **`cpp-oop/`** — object-oriented C++: `zoo-inheritance`, `complex-number-class`, `rational-class`, `avl-tree`, `bst-employees`, `time-class`.

Folders named `_versions/` hold earlier saved versions of the same exercise, kept for reference.

> Course submissions kept for reference. Personal ID numbers have been removed.
