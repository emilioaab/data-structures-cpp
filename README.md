# Data Structures & C/C++ coursework

Exercises, labs and assignments from the C and C++ / data-structures courses at SCE.
Each folder is a standalone exercise (linked lists, trees, hashing, sorting, strings,
dynamic arrays, a Complex-number class, and more).

**Languages:** C, C++  ·  **Build:** CMake per exercise.

> Course submissions kept for reference. Personal ID numbers have been removed.
